ABOUT THE PLATFORM

Built for Game Developers

Welcome to Game Builds! This platform is designed to make sharing early game builds simple and direct, whether made in Unity, Godot, or custom engines.

Developers can push WebGL builds directly to the browser or upload downloadable desktop executables (.zip / .exe) along with active changelogs.

Players can jump right into games, test new versions as development progresses, and leave ratings and feedback to help developers improve their games.

SUPPORTED ENGINES Unity, Godot & WebGL
BUILD TYPES Browser & Desktop (.exe)
